More detail — the numbers, and how to keep it

Why one name per box is worth the trouble. Every box is a separate thing to name, so a picture of four people teaches four things instead of one — each of them learned from the box it sits in rather than from the whole frame. It is also how real image collections are labelled, one region at a time. Underneath, the network answers a separate yes/no for each thing it knows rather than picking a single winner from all of them, which is why more than one name can clear the line at once.

Privacy

Every picture you show it is read on your own machine. There is no server behind this page, nothing is uploaded, and no request in the model code could carry a picture anywhere — the whole demo works with the network switched off. That is true whatever you answer about cookies.

What it learns is kept in this browser's own storage, so closing the tab and coming back picks up where you left off, and Forget everything erases it. Saving its memory downloads a file to your machine; loading one back is a file you chose. Nothing about you is stored here and there are no accounts.

Cookies

That leaves one cookie, and it is optional: Google Analytics, which records anonymous page, click and scroll events — never anything you type, and never a picture you show it. Google's script is not in this page at all. It is added only if you allow it, so a visit that rejects makes no request to Google and receives no cookie.

Your answer is remembered in your own browser's storage, not in a cookie — setting a cookie to record a cookie decision would be its own small joke. You can change it whenever you like from Cookie settings in the footer, which opens the same panel that Settings does while the question is up. Questions about this policy go to privacy@nodejavascript.com.
