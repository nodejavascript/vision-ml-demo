Teach a network to see your images

A small convolutional network — convolutions, pooling, backpropagation, Adam — written from scratch in TypeScript and compiled to the plain JavaScript your browser runs. No framework, no bundler, no runtime dependencies, no server, no API key. Give it a few pictures, tell it what the ones it cannot name are, and watch the loss fall.

  • Your images never leave this page. There is no server behind it; the model trains in a Web Worker on your own machine.
  • It asks instead of guessing. When it is not sure, it says so, and the picture goes into a queue for you to name.
  • It remembers. The model is saved in this browser as you go, and downloads as a file you can load again later.
Prototype. This page is not deployed. It is a local build, with no analytics and no tracking of any kind — which is also why it can honestly say nothing is uploaded.

How it works

An image is reduced to 48 × 48 pixels and turned into numbers. Two convolutions slide small 3 × 3 kernels across it, each followed by a rectifier and a 2 × 2 pooling step, which is what gives the network its tolerance to a shape appearing a few pixels to the left. What survives is flattened and passed through two dense layers to a softmax over your classes. About 75,000 weights in total.

Training is backpropagation with Adam. The gradient flows backwards through the dense layers, then back through the pooling — where each value returns to whichever pixel won it — and then backwards through the convolutions, where every kernel is credited with what it contributed and every input pixel is charged for every kernel that read it. The loss plotted above is cross-entropy; the accuracy is measured on images held back before training began, so it is a test rather than a memory.

What it is not

  • It is not a good model. Two convolutions and 75,000 weights is a demonstration of the mechanism, not of the state of the art. A real image classifier is a thousand times larger and trained on a million times more pictures.
  • It needs examples of each thing. It can only learn the classes you give it, and it will happily learn the wrong thing if your pictures differ in brightness rather than in subject.
  • It will be confident and wrong. A softmax always adds to one, so a two-class model is guaranteed to be 60% sure of something. That is exactly why the page asks instead of deciding.
  • It is not persistent across browsers. The saved model lives in this browser's storage. Download it to keep it properly.
